# auth: сбои

| Ответ `POST /api/auth/exchange` | Ошибка | Текст на странице входа |
|---|---|---|
| 204 | нет | переход на `/` |
| 401 (ссылка просрочена, уже использована, подделана) | `InvalidLoginLink` | "Откройте редактор командой /editor в боте." |
| нет `token` в адресе | запрос не делается, `InvalidLoginLink` | то же |
| сеть, 5xx, таймаут | `BackendUnavailable` | "Сервер не отвечает. Попробуйте позже." |

Повторов нет: токен одноразовый, второй запрос с ним даст 401.
