# settings: сбои

| Ситуация | Ошибка | Что видит человек |
|---|---|---|
| 401 | `SessionExpired` | переход на `/login` |
| Настройки не загрузились | `BackendUnavailable` | вместо формы "Сервер не отвечает. Попробуйте позже." |
| Поле не прошло проверку | нет запроса | красная рамка и текст у поля (артборд `SettingsErrors`) |
| Сервер ответил 422 | `SettingsInvalid` | "Сервер не принял значения. Проверьте поля." рядом с кнопкой |
| Сбой при сохранении | `BackendUnavailable` | "Сервер не отвечает. Попробуйте позже." рядом с кнопкой; введённое остаётся в форме |
| Успех | нет | "Сохранено" рядом с кнопкой (артборд `SettingsSaved`) |
