# settings: инварианты

| Правило | Где держится |
|---|---|
| Часы не уходят на сервер, если не целое число от 1 до 168 (0, 169, 1.5, пустое поле) | `validate` в store, тесты `test_save_reminder_rejects_zero_hours` и таблица значений |
| Текст из пробелов не уходит; длина считается после `trim`, 1024 знака проходят, 1025 нет | `validate`, тест |
| Обе ошибки показываются сразу, каждая у своего поля | `store.errors` |
| На сервер уходит `text` после `trim` | `store.save` |
| В настройках нет менеджерского чата: ни поля, ни значения | типы, форма |
| Границы совпадают с backend (`hours` 1..168, `text` 1..1024) | [API.md](../../services/API.md) |
