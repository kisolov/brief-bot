# leads: инварианты

| Правило | Где держится |
|---|---|
| Фильтр работает над полным списком, выбранная заявка всегда видна: при смене фильтра пропавший выбор заменяется первой видимой, в пустом списке выбора нет | `store.keepSelection`, тесты `test_filter_by_status`, `смена фильтра переносит выбор` |
| Имя в карточке это ответ "Имя", иначе "Заявка #id"; в таблице перед номером идёт `@username` | `leadName`, `leadClient` |
| Телефон, Мессенджер, Удобное время идут в верхний блок и не повторяются в списке; "Имя" в списке не показывается | `leadTop`, `leadRest` |
| Подпись ответа приходит человеческой, фронтенд её не переводит | `display_key` на backend |
| Брошенная заявка показывает `lastStep` в статусе | `leadStatus`, тест `test_partial_lead_shows_step` |
| Время показывается местным: "Сегодня", "Вчера", "28 октября", с годом, если год не текущий | [when.ts](../../../editor/app/utils/when.ts) |
| В ответах нет `chatId`, `fileId` и менеджерского чата, редактор их не знает | контракт [API.md](../../services/API.md), тип `Lead` |
