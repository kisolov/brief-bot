# leads: сбои

| Ситуация | Ошибка | Что видит человек |
|---|---|---|
| 401 на любом запросе | `SessionExpired` | переход на `/login` |
| Список не загрузился (сеть, 5xx) | `BackendUnavailable` | вместо таблицы "Сервер не отвечает. Попробуйте позже." (артборд `LeadsError`) |
| Заявок нет | нет | "Заявок пока нет." (артборд `LeadsEmpty`); в карточке "Выберите заявку в списке." |
| ТЗ больше 20 МБ (413) | `FileTooLarge` | под ссылкой "Файл больше 20 МБ. Telegram не отдаёт такие файлы ботам." (артборд `LeadsFileError`) |
| Файла или заявки нет (404) | `LeadNotFound` | под ссылкой "Заявка или файл не найдены." |
| Прочий сбой скачивания | `BackendUnavailable` | "Сервер не отвечает. Попробуйте позже." |

Ошибка скачивания принадлежит заявке: при выборе другой строки она пропадает. Повторов нет, человек нажимает ссылку снова.
