# access: сбои

| Сбой | Поведение | Где |
|---|---|---|
| Токен неизвестен, просрочен, использован или не того вида | `InvalidEditorToken`, HTTP 401, один `WARNING "Business rejection"` | [exception_handlers.py](../../../backend/src/bootstrap/utils/exception_handlers.py) |
| Нет cookie или она негодна | то же: 401 | [session.py](../../../backend/src/bootstrap/utils/session.py) |
| `/editor` от чужого аккаунта или с неверным кодом | `NotAdmin`, в чат уходит `Эта команда только для администраторов.`; логов с кодом нет | router |
| База недоступна при проверке сессии | исключение уходит наружу, HTTP 500: запрос без проверки не пропускается | `CheckEditorSession` |
| Два браузера открыли одну ссылку | сессию получит один, второй 401 | `consume_link` |
| `EDITOR_BASE_URL` не задан | приложение не стартует: `ValidationError` до подключения к базам | `lifespan` |

Ограничения:

- Просроченные строки `editor_tokens` не удаляются: таблица растёт на одну-две строки за вход.
- Отозвать конкретную сессию нельзя; лишить доступа администратора можно только удалением строки из `admins`, уже выданные сессии доживут до конца срока.
- Ограничения частоты `/editor` нет.
- Cookie с `Secure` не сохраняется браузером по обычному `http` (кроме `localhost`): редактор должен открываться по https.
