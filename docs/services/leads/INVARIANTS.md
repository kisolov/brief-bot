## Формат текста

Строки по порядку: `Новая заявка` или `Частичная заявка`; `Направление: <branch>` если не пусто; `Telegram: @<username>` если есть; `Последний шаг: <last_step>` для partial, если есть; затем `<ключ>: <значение>`. Длина части это единицы UTF-16 (так считает Telegram), не code points: эмодзи вне BMP весит 2. Лимит 4096 единиц. Части режутся по границе строк; строка длиннее лимита режется жёстко по единицам UTF-16, суррогатная пара не рвётся (между кусками такой строки перевода строки нет). Соединив части через `\n`, получаем исходный текст, кроме жёстко разрезанных строк. Пустая строка на стыке частей сохраняется (часть начинается с `\n`). Пустые и состоящие из пробелов части отбрасываются: Telegram их отклоняет (`message text is empty`).

## Логи

Только `lead_id` и `status`; телефоны, имена, значения ответов в логи не попадают.
